# my_research_work

## BenchmarkKit

An LLM inference and RAG benchmarking toolkit for measuring latency, throughput, token cost, retrieval recall, and answer support across serving frameworks.

See [`benchmarkkit/README.md`](./benchmarkkit/README.md) for installation, Docker setup, dataset preparation, and contribution guidance.

## Personal Chief of Staff

A local-first, LangGraph-supervised MCP assistant for daily briefings, email triage, meeting preparation, and calendar suggestions. Demo mode uses synthetic data; live integrations are user-configured and read-only.

See [`personal-chief-of-staff/README.md`](./personal-chief-of-staff/README.md) for setup, architecture, MCP configuration, and safety boundaries.

## Chat with My Research

A citation-first, local-corpus RAG application with MCTS, A*, beam search, and multi-hop retrieval evaluation. The included corpus is synthetic; no private papers or talks are included.

See [`chat-with-my-research/README.md`](./chat-with-my-research/README.md) for setup, planner comparisons, search-tree visualization, and evaluation.
